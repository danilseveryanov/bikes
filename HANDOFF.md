# Где мы остановились

Рабочая записка для продолжения. Живёт в репозитории, чтобы пережить любое
сжатие переписки. Отчёт с таблицами:
https://claude.ai/code/artifact/6c07b056-6422-449d-bfb0-f2cefd5384bd

## Одной строкой

Сайт переезжает с GitHub Pages + Cloudflare на свой VPS в Тайм-вебе — тот же
сервер, где живёт бюджет ДИТ (`109.68.212.36`). Причина не в лимитах: зона
`workers.dev` в России заблокирована, и синхронизация работала только через VPN.
Приложение уже развёрнуто и работает на сервере: данные перенесены (ревизия 14),
`index.html` побайтово совпадает с проверенной сборкой. Не хватает трёх вещей,
которые я сделать не могу, — см. «Что осталось».

## Как устроено

- `index.html` **собирается**: правим `src/app.html` + `data/*.json`, затем `python3 build.py`.
- Проверки: `node test.js` — вытаскивает функции прямо из `src/app.html`, разойтись не могут.
- `server/server.js` — сервер на Node без зависимостей: отдаёт страницу, шрифт
  и API. Состояние в `/var/lib/bikes/state.json`, копия раз в сутки, хранится месяц.
- Договор API тот же, что был у Worker'а, только с приставкой `/api`:
  `GET /api/doc` открыт всем, `POST /api/login`, `GET /api/me`,
  `PUT /api/doc` с `If-Match` — 409 при устаревшей ревизии.
- Страница и данные теперь на одном origin, поэтому CORS нет вовсе,
  а `connect-src` в политике безопасности сузился до `'self'`.
- Раскатка: `./server/deploy.sh` — идемпотентна, повторный запуск безопасен.
  Собирает, гоняет тесты, заливает, поднимает systemd-юнит и vhost в nginx.
- Пароль: `node server/set-password.mjs`. Итераций PBKDF2 **200 000** —
  потолка процессорного времени, из-за которого в Worker'е стояло 60 000, здесь нет.
- `worker/` остаётся архивом. Две живых копии с разным состоянием опаснее,
  чем отсутствие запасной, — после переезда Worker выключить.

## Что осталось

За владельцем:
1. **A-запись `bikes.severyanov.site` → `109.68.212.36`.** DNS домена держит
   reg.ru. `budget.severyanov.site` уже смотрит туда — делать так же.
2. **Пароль сайта**: `node server/set-password.mjs`. Ввести его должен он сам —
   пароль не проходит через переписку. До этого сайт открыт только на чтение,
   вход отдаёт 503.
3. **Пока не переключились — не править старый сайт на github.io.** Он всё ещё
   пишет в Cloudflare, а сервер сидит на ревизии 14. Правка там разведёт копии.
   Если всё же правил — перед переключением сверить ревизию в облаке
   с `/api/doc` на сервере и перенести заново.
4. Пробеги остальных велосипедов — заполнен только Rider Boost. Без пробега
   молчат «пора менять», стоимость километра и прогноз.
5. Фотографии — ни одной (загрузка была сломана, теперь чинена, см. ниже).
6. `soldPrice: 0` у twitter-gravel-v1 — из-за нуля итог владения показывает
   полный убыток. Спросить, прежде чем менять.
7. Три записи «Сборка велосипеда» по 12 000 ₽ (две от 14.08) — похожи на дубли,
   завышают год на 24 000 ₽. Не удалять без спроса.

За мной, как только появится A-запись:
8. `certbot --nginx -d bikes.severyanov.site --agree-tos -m danilseveryanov@gmail.com --redirect -n`
9. Погасить GitHub Pages в настройках репозитория (владелец выбрал «совсем»,
   без редиректа) и отвязать Worker.
10. Цены в открытом репозитории — владелец согласен, но перенос состава на

## Ловушки — не «чинить» обратно

- `mergeDocs` сливает словари **поключево**. Иначе стёртое устройство обнуляет
  облако: миграция на старте штампует свежий mtime, и пустой документ выглядит
  новее. Снятая галочка пишется `0`, а не удаляется.
- Всё из документа экранируется при выводе + `sanitizeDoc()` на входе. Политика
  безопасности с хешем скрипта считается в `build.py`; `font-src data:` нужен
  для вшитой гарнитуры.
- **Фото читаются через `FileReader` в `data:`, а не через `createObjectURL`.**
  `img-src` разрешает только `'self'` и `data:` — `blob:` политика блокировала
  молча, `onload` не срабатывал, и добавить фото было нельзя вообще. Это был
  настоящий баг, а не придирка: в облаке за всё время ноль фотографий.
- Правило ТО с `est_part_cost: 0` — это осмотр, он не наследует цену детали.
- Прогноз — годовая частота, а не накопленный долг.
- `purchaseTotal` падает на `totalSpend`, если состав не расписан по позициям.
- Переименование пункта чек-листа рвёт привязку галочки: имя входит в
  устойчивый id. Каждое переименование — в `RENAMES`, применяется до правки текста.
- В таблице рам: `SUM weight` пропускает TBD (Argon 18 был бы «легче всех»);
  легенда top/ok/nah не проставлена ни в одной строке — не выдавать расчётный
  балл за мнение автора; цены фреймсета и целого велосипеда не смешивать.
- `deploy.sh` переносит документ из Cloudflare **только когда на сервере ещё нет
  состояния**, и падает, если облако недоступно. Это нарочно: подняться пустым
  и дать владельцу войти — значит записать пустой документ поверх настоящего.

## Оформление (принято 20.08, менять только по просьбе)

- **Схематичных велосипедов нет нигде** — владелец их отверг как «слишком ИИ».
  Карточка = кадр под фото, пустое состояние намеренное.
- **Время суток** правит всю палитру: рассвет 5–8, день 8–17 (светлый интерфейс),
  закат 17–21, ночь. `data-part` на `<html>`, 33 переменные на палитру.
- **Разделы — места по маршруту**: набережная, двор-колодец, проспект,
  мастерская, грунтовка. Небо общее и не едет, земля идёт тремя планами
  (6% / 13% / 20%) — переключение читается как проезд.
- Глубина вместо плоских заливок: слои света, туман, отражение, зерно.
- Гарнитура Unbounded, кириллический срез вшит (`assets/Unbounded.woff2`).
- Луна — не перекрашенное солнце: холодный диск с кратерами, только ночью.

## Как проверять (предпросмотр чинится, вопреки прежней записи)

Предпросмотр отдавал 404 не из-за сервера. `~/Documents` защищён механизмом
приватности macOS: процессу, запущенному панелью предпросмотра, `stat` по файлу
разрешён, а `open` — нет, поэтому `SimpleHTTPRequestHandler` честно отвечал
404 на существующий файл. **Лечится копированием собранного сайта во временный
каталог вне `~/Documents` и раздачей оттуда** — так проверены и переезд, и
починка фотографий.

Полная локальная копия сервера поднимается так (пароль — любой свой, тестовый):

```
APP_DIR=<каталог с index.html и assets> DATA_DIR=<каталог для состояния> \
AUTH='pbkdf2$200000$<соль>$<хеш>' PORT=8790 node server/server.js
```

И всё же: два раза уже уезжало вслепую (мир под панелью, луна-солнце) —
**просить владельца посмотреть глазами.**
