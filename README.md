# Велосипеды — гараж, ТО и затраты

Личный сайт: парк из 5 велосипедов, состав и закупочные цены, регламент ТО с
журналом обслуживания, затраты за год, обзор 92 гравийных рам 2027 и чек-листы
сборки.

Живёт на <https://danilseveryanov.github.io/bikes/>

## Как устроено

Одна страница `index.html` — вся вёрстка, вся логика и все данные внутри. Ничего
не грузится по сети, поэтому сайт открывается офлайн и не зависит ни от CDN, ни
от CORS.

`index.html` **собирается**, а не правится руками:

```bash
python3 build.py
```

Скрипт берёт `src/app.html` и подставляет в него `data/*.json`. Правьте
`src/app.html` и `data/`, потом пересоберите.

```
src/app.html          вёрстка + логика, с плейсхолдером __DATA__
data/bikes.json       5 велосипедов, компоненты, закупочные цены
data/maintenance.json 22 правила регламента ТО
data/frames.json      92 рамы, нормализованные + расчётный балл
data/checklists.json  чек-листы сборки, перенесены дословно со старой страницы
data/log.json         сид истории обслуживания (см. «Если Safari почистил память»)
test.js               проверка агрегаций, которые рисуют графики
worker/               хранилище для синхронизации между устройствами
```

Проверка расчётов:

```bash
node test.js
```

Тест вытаскивает функции агрегации прямо из `src/app.html`, а не из копии, —
он не может разойтись с тем, что реально опубликовано.

## Синхронизация между устройствами

Рабочее хранилище — `localStorage` под ключом `bikes:v1`: сайт мгновенно
открывается и работает без сети. Облачная копия — один JSON-документ в
Cloudflare KV за крошечным Worker'ом (`worker/worker.js`, ~40 строк).

**Развёрнуто 14.08.2026.** Адрес хранилища:

```
https://bikes-sync.severyanov.workers.dev
```

На каждом устройстве: кнопка «Синхронизация» в шапке сайта → вписать этот адрес
и ключ. Всё, телефон и компьютер видят одни и те же данные.

Ключ хранится как секрет Worker'а (`SYNC_KEY`) и нигде больше не лежит. Если
потеряли — задайте новый, данные при этом не пострадают:

```bash
cd worker && npx wrangler secret put SYNC_KEY
```

Если понадобится развернуть заново с нуля:

```bash
cd worker
npx wrangler kv namespace create BIKES   # id → wrangler.toml
npx wrangler secret put SYNC_KEY
npx wrangler deploy
```

Ключ открывает **только этот документ**. Он не даёт доступа ни к репозиторию, ни
к аккаунту GitHub, ни к аккаунту Cloudflare. GitHub-токен в публичном фронтенде
не используется и использоваться не должен: он виден через «просмотр кода»
любому посетителю и даёт запись в репозиторий, из которого раздаётся сайт.

### Как не потерять данные при одновременной правке

`GET` отдаёт `{rev, doc}`, `PUT` присылает `If-Match: <rev>`. Устройство,
которое правило старую версию, получает 409, перечитывает, сливает и повторяет.
События сливаются по `id` и никогда не затираются молча; удаление — это флаг
`deleted`, а не исчезновение записи, иначе удаление не пережило бы слияние.

### Если синхронизацию не поднимать

Сайт работает и так, только данные останутся на одном устройстве. В окне
«Синхронизация» есть выгрузка и загрузка резервной копии файлом — на iPhone она
уходит через «Поделиться» в Файлы или iCloud.

### Если Safari почистил память

Safari стирает `localStorage` у сайтов, не открывавшихся ~7 дней, а раздел ТО —
как раз такой. Если облачная копия подключена, всё вернётся из неё при первом
открытии. Дополнительная страховка — `data/log.json`: что закоммичено туда,
восстанавливается всегда, даже офлайн.

## Перенос галочек со старого чек-листа

Старая страница `faraoll-g50-checklist` хранила отметки под ключами
`faraoll-g50-checklist-v3` и `speedone-275-checklist-v1` в виде
`"<индексГруппы>-<индексПункта>"`.

Оба сайта живут на одном origin `danilseveryanov.github.io` — путь в origin не
входит, поэтому `localStorage` у них общий и отметки читаются напрямую.
Миграция переводит позиционные ключи в устойчивые `slug(группа)/slug(пункт)` и
происходит **до** любых правок содержимого: позиционный ключ имеет смысл только
против неизменённых массивов, иначе отметки молча переедут не на те пункты.
Поэтому `data/checklists.json` перенесён дословно.

Старые ключи не удаляются — это единственный откат.

**Если когда-нибудь привяжете свой домен**, `localStorage` туда не переедет:
origin изменится. Сначала выгрузите резервную копию, потом меняйте домен.

## Откуда цифры

- **Закупочные цены** — из вашей сметы, как есть.
- **Регламент ТО** — у каждого пункта подписан источник: «спецификация
  производителя» (пределы износа Shimano, интервалы RockShox) или «оценка».
  Оценки — это оценки, а не паспортные данные.
- **Балл рамы** — расчётный, мой. В исходной таблице есть легенда с категориями
  top/ok/nah, но автор не проставил их ни в одной строке, поэтому его вердикта в
  данных просто нет; показывается его текстовый комментарий. Рамы без веса, цены
  или размера покрышки в рейтинг не попадают — иначе рама выигрывала бы за счёт
  отсутствующих данных. Цены фреймсетов и целых велосипедов сравниваются только
  внутри своей группы.
